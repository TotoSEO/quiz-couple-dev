Comment trouver mon Google Place ID ?

Méthode recommandée :

  1. Ouvrez l'outil officiel Google : Place ID Finder
  2. Tapez le nom de votre cabinet dans la barre de recherche (ex : "Cabinet Dupont therapie Paris")
  3. Cliquez sur votre établissement dans les suggestions
  4. Le Place ID s'affiche automatiquement dans l'encadré (commence par ChIJ)
    Place ID : ChIJe2jeNttx5kcRXwGMo8coG1w
  5. Copiez-collez ce code dans le champ ci-dessus
Attention : le Place ID n'est pas visible directement dans l'URL de Google Maps. Utilisez l'outil ci-dessus pour le trouver facilement.
