Comment trouver mon Google Place ID ?
  1. Ouvrez Google Maps
  2. Recherchez le nom de votre cabinet (ex : "Cabinet Dupont therapie Paris")
  3. Cliquez sur votre etablissement dans les resultats
  4. Regardez l'URL dans la barre d'adresse de votre navigateur
  5. Repérez le code qui commence par ChIJ dans l'URL
    google.com/maps/place/.../ChIJe2jeNttx5kcRXwGMo8coG1w
  6. Copiez-collez ce code (commencant par ChIJ) dans le champ ci-dessus
